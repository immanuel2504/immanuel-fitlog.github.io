# Immanuel Fitlog

A responsive, offline-friendly workout tracker for strength training, calisthenics, and yoga.

## Features

- Six-day workout-plan support with rest days
- Strength Training, Calisthenics, and Yoga tabs
- Exercise categories and custom exercises
- Workout logging, history, and progress graphs
- JSON workout-plan replacement
- Local backup, restore, and CSV export
- Responsive desktop and mobile interface

## Use

Open `index.html` in a browser or visit the GitHub Pages website.

Workout information is stored locally in the browser. Export a backup regularly and import it when moving to another browser or device.
